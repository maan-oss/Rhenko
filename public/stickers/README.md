# Sticker artwork

The emoji stickers in this folder are Twemoji graphics.

- Source: Twemoji, https://github.com/twitter/twemoji
- Graphics license: CC-BY 4.0, https://creativecommons.org/licenses/by/4.0/
- Copyright: Twitter, Inc. and other contributors

Each file is unchanged from the source, named by its code points. The list of files in use is `EMOJI_STICKERS` in `lib/stickers.ts`.
Credit is shown in the sticker tray in the composer, as CC-BY 4.0 asks.
